# Experiments

This directory contains runnable workflows for the manuscript experiments. Generated outputs are written under `outputs/` directories and ignored by Git.

- `benchmarking/`: comparison against external deconvolution methods.
- `benchmarking/dlpfc/`: DLPFC sample-wise benchmarking and ARI summaries.
- `ablation/`: SNMF ablation studies.
- `runtime/`: CPU/GPU runtime comparison.
- `melanoma/`: biological validation notebook and SNMF run command.

All shell wrappers accept paths relative to the repository root.
